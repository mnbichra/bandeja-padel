# Bandeja · réservation de terrains de padel

Application web mobile de réservation de terrains de padel (MVP), pensée pour les clubs au Maroc.

**Site en ligne :** https://mnbichra.github.io/bandeja-padel/

## Fonctionnalités
- Disponibilités sur 8 jours, créneaux de 60 ou 90 min, filtre intérieur / extérieur
- Prix par joueur affiché, heures creuses / pleines, aucun frais caché
- Récapitulatif avec politique d'annulation (gratuite jusqu'à 24 h avant)
- Billet avec code et QR code, partage WhatsApp
- Mes réservations et annulation
- Espace club : planning du jour, encaissement, blocage de terrain, tarifs

## Mode démo
Sur GitHub Pages, l'application fonctionne en **mode démo** : les réservations restent dans le navigateur du visiteur et ne sont pas partagées. Le partage en temps réel entre joueurs nécessite une base de données en ligne (prévu : Supabase).

## Technique
Un seul fichier `index.html` (HTML, CSS et JavaScript, sans dépendance à compiler).
